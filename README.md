## 🧾 Overview

**Furniro** is a modern front-end furniture shop built for aesthetic product presentation and smooth user interaction.  
It demonstrates a clean, minimalist design using React (or HTML/CSS/JS depending on your setup) and is optimized for responsiveness across devices.

The site contains:
- A hero section introducing the brand.
- Product listings with prices, discounts, and hover effects.
- Shop and category sections (Living Room, Bedroom, Office, Outdoor, etc.).
- Product detail previews with “Add to Cart”, “Share”, and “Like” icons.
- A responsive navigation bar and footer.
- Smooth animations and scroll effects.
- Fully deployable via **Netlify** or **Vercel**.
